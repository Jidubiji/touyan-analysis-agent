# 数据与来源核验

## 最小来源记录

在工作文件中保留标的、来源、检索时间、交易所时区、交易时段、周期、OHLCV、调整方式、已验证公司行动以及转换规则。最终输出保留用户理解图表所需的日期、口径和来源。

实时、延迟、盘前和常规收盘各自保留时间戳。主图默认以最新完整常规交易日为截止。若当天仍在交易，注明未完成日线，或将盘中报价单独列出。

## 获取历史与处理返回限制

- 用户指定数据源时优先使用该来源。否则优先使用可调用的专业市场数据工具，例如长桥。先读取当前工具说明，确认权限、参数、返回结构和时区。
- 行情工具不可用时，可使用用户提供的 OHLCV 文件并核验口径、范围与截止时间。按已具备的数据完成对应周期，披露缺失范围。
- 获取周线、日线、小时线以及所选指标需要的预热数据。根据真实交易时长、节假日和指标长度计算所需数量。
- 图中展示一年的 200 日均线，需要在第一根展示 K 线之前保留至少 199 根有效日线。EMA、MACD 应有足够预热，若预热不足需标出受影响部分。
- 美股常规时段 6.5 小时。按 9:30 起算的 60 分钟聚合通常有 7 根，末根为 30 分钟。读取实际聚合规则，保持整段历史一致。
- 优先用日内或常规交易时段参数获取结构图。盘前盘后另行展示，或在图中清楚标明混合时段。
- 返回过大时可选择时间、OHLCV 等必要字段，按日期分段或分页获取。检查实际返回范围和条数。出现截断警告时，继续获取缺失部分。
- 拼接前核对重叠区间、时间戳和来源版本。重叠记录冲突时，查清调整状态或更新时点，再决定采用的版本。

## 公司行动与价格对齐

明显价差可能来自拆股、合股、币种、时段、代码或缓存。先定位原因，再转换价格。

1. 从发行人、基金公司、交易所或监管文件核实公司行动比例、实施日和开始按新股数交易的日期。
2. 分别检查实时行情、日线、周线、小时线的调整状态，尤其关注生效日附近的缓存差异。
3. 选择统一口径，通常采用当前股数基础的价格。保留原始序列，在分析副本中转换。
4. 对尚未调整的一拆 N 历史序列，价格除以 N、股数成交量乘以 N。对合股采用对应的逆向关系。已经调整的序列沿用其口径。
5. 现金分红的价格调整方式依数据源定义处理，股数成交量保持其实际单位。多次拆股时按日期逐次应用正确因子。
6. 核对重叠日期和最新完整收盘的 OHLC，确认全部图表、均线、关键价位和最新报价使用同一基础。

除权除息图表的价格调整、基金净值和投资者总回报各有定义。涉及总回报比较时，明确分红再投资等假设。

## 聚合核对

至少检查以下内容。

- 时间单调、时间戳唯一、OHLC 满足价格关系、成交量非负，缺失或异常点已定位。
- 小时线按交易日聚合后，与日线开盘、最高、最低、收盘和总量比较。
- 日线按交易周聚合后，与周线对齐。周一或周五标签是时间标记差异，核对实际覆盖交易日。
- 不同时段、报价源、成交汇总范围和小数精度可能产生差异。价格结构采用可靠价格序列，成交量判断采用可靠总量，分别记录限制。
- 若极值或量能差异改变关键判断，使用另一行情来源交叉核对受影响日期。日内数据不足时完成有可靠依据的周线和日线部分，并说明小时图范围。

可以用同口径日线重建近期周线，保证所标关键价位一致。遇到周线未完成、停牌或交易日不完整时，明确覆盖范围。

## 指标约定

| 指标 | 默认计算 | 使用重点 |
| --- | --- | --- |
| 周线趋势参考 | 40 周 SMA | 位置、斜率、完整周收盘 |
| 日线趋势参考 | 20、50、200 日 SMA | 与价格结构相互印证 |
| 小时趋势参考 | 20、60 根 SMA | 近期修复和回踩 |
| MACD | 12、26、9 | 对应波段的动量变化 |
| RSI | 14 | 动量及价格与动量的分歧 |
| ATR | 14 | 波动环境，同时报告 ATR / 价格 |
| 放量倍数 | 当日量 / 此前 20 日均量 | 分母排除当日 |

优先复用现有经过检查的计算库，例如 TA-Lib。缺失值保留其缺失状态。使用其他实现时注明种子、平滑和直方图定义等会影响比较的差异。

MACD 默认使用收盘价计算，柱体为 DIF−DEA。沿用其他柱体定义时，在三个周期、正文与图例中一致注明；数值仅在相同定义与价格口径下比较。交叉判断使用完整精度，图中数值按可读精度展示。近期放大图沿用完整序列计算值。具体对应与微小交叉处理见 [MACD 研判与标注](macd-annotations.md)。

均线等指标是动态数值。将截至分析日的均线区域用于后续观察时，提醒其会随行情更新。

完整向下跳空的边界为当日最高价与前一交易日最低价，成立条件是当日最高价低于前日最低价。向上跳空采用对应的反向关系。按后续常规时段行情更新填补状态。

## 比较标的

用户需要或相对强弱能改变判断时，可选行业同类 ETF 与宽基指数比较。对齐日期、分红处理和价格口径，并明确基期。

行业 ETF 常共享持仓，其同向变化提供的增量信息需要结合成分重叠理解。应用道氏类相互确认思想时，说明这是对相关市场结构的扩展使用。
