# Fundamental Intelligence Agent V1.3 — 验收与回归测试

> 以下均为**合成测试情景**，不是任何上市公司真实披露。没有真实数据连接时，先测试逻辑正确性与信息缺失处理。测试标识和期望状态可作为后续自动化测试的断言。

## 运行前提

- 每个情景提供事件发生日、公开发布日期、研究 `as_of`、核心来源/页码、指标口径及必要的历史观察值。
- 验收至少检查：是否拒绝非法结论、状态升级合理、是否提供两种解释、是否保留原始版本、能否复算、是否重复告警。
- 多源引用如源自同一原始披露，必须去重。

| 测试 ID | 合成输入 | 期望行为（不可省略） |
|---|---|---|
| T01 | 仅提供财报和 10-Q，没有会议逐字稿 | 标 `transcript_unavailable`，不虚构 CEO/CFO Q&A |
| T02 | Q3 10-Q 现金流为年初以来 9 个月累计 | 用 Q3 YTD−Q2 YTD 还原单季并列公式，或报告缺失 |

| T09 | 原指引 10–12，后修订 8–9，实际 9（相同口径） | 对最新指引达成，但完整显示原始指引被下修及版本链 |

| T13 | 同一家公司新闻稿被三家媒体转载 | 仅认一个原始事实来源，不算三份独立交叉验证 |

| T15 | 财报后新版一致预期被用作财报前“预期基准” | BLOCK：时间穿越，拒绝 beat/miss 结论 |
| T16 | 没有发布时间匹配的预期及股价快照 | 只允许经营层讨论；拒绝“市场尚未定价”和目标价 |
| T17 | 同一异常已推送，后续仅转载和无实质变化 | 不重复提醒；但正式更正触发修正提醒 |
| T18 | 异常仅连续 1 季、没有重大事件或外部佐证 | `candidate/under_review`，不得自动升级到 `thesis_material` |
| T19 | 旧预测宣称 Q4 营收会加速，后来实际减速 | 保留旧版本，评估误差及归因；不得改写旧预测 |
| T20 | 行业强景气但公司增收靠增发与巨额 CapEx，FCF/股明显恶化 | 触发 `A4_capital` 和 `A5_quality`，结论必须考虑每股股东价值 |

| T29 | 新业务盈利机制与旧业务不同，旧PE很低，新利润尚未稳定 | 禁用跨阶段Forward PE百分位；标`historical_percentile_unavailable`并提供情景 |
| T30 | Foundry业务发生硬断点，另一稳定成熟业务从未变更 | 逐业务/KPI裁定；不得将两者全部标成`noncomparable`或重置集团全部历史 |
| T31 | 公司宣布新商业模式但产品未上市，未产生收入 | `announced`且`soft_transition/unknown`；不能以宣布日起用新盈利模型作已兑现事实 |
| T32 | 管理层换届；前任的预测已经到期，现任发布不同预测 | 分开发言人及责任；保留公司原始承诺的连续版本，不让新高管承担个人旧承诺 |
| T33 | 旧阶段收入下降，研究员将断点日期向后移动以截掉不利季度 | 阻断选择性窗口；需引用客观生效日、给出双视角和重选理由 |
| T34 | 公司只对分部收入做历史备考重建，无正式利润重列 | 收入可标`bridged_estimate`，利润不得跟着标可比；保留误差与来源 |
| T35 | 上下游行业周期整体衰退，公司也受影响，但公司无重大经营机制变化 | 标`market_cycle_shift`背景，不能因此自动确认公司商业模式硬断点 |
| T36 | 旧产能已出售，但仍有未清偿债务或或有负债 | 资产处置不自动清除融资/合同义务；FCF和股东权益桥继续计入余额 |
| T37 | 旧厂每年计提高额折旧，同时已支付的资本支出计入CapEx | 折旧影响利润、税和ROIC，但不能在经营现金流扣除后又当成资本性现金支出重复扣减 |

**V1.2 关键验收口径**：`regime_id` 与每个核心 KPI 对应；断点事件时点有真实来源；同口径样本数不造假；正式重列/备考/原始披露分开；现任承诺和旧资产责任分开；现金流模型不能因换任而“清零”资本历史。

### 测试运行与失败记录（不可跳过）

1. 每个编号保存 `test_id, ruleset_version, input_fixture, as_of, expected_output, actual_output, severity, passed, reviewer, executed_at, evidence_log`。没有 `actual_output` 和真实执行日志，标**未执行**，不能算通过。
2. 先跑T01–T37确保原功能未退化，再跑T38–T73；分开报 `documentation_lint`、`scenario_execution`、`historical_out_of_sample`，三者不可互相冒充。
3. 对任意P0失败，阻断受影响结论并标版本为`needs_revision`；P1失败允许条件研究但禁止完成估值判断；P2列残余问题。
4. 把谷歌与英特尔作为**历史案例的待执行计划**，用相同信息截止时点跑V1.2和V1.3，记录：重大遗漏率、会计/口径错误率、未经证实的估值结论率、反证覆盖率、财务传导可复算率、样本量及盲测分母。没有执行则不宣称提升。

## 拒绝发布条件

任一 BLOCK 触发时，相关重大结论不得作为确定事实发布。报告仍可提供已核验的其它信息、清晰的证据缺口和需要补充的资料清单。

## 定期复核指标

- `false_positive_rate`：被撤销/明显证伪的异常占符合可观察窗口的历史候选数量。
- `detection_lead`：在研究时点可证实的异常首次提示到后续公开验证之间的间隔；未验证样本不能随意记胜率。
- `guidance_audit_coverage`：已到期且可核验承诺占需审计承诺的比例，显示分母。
- `forecast_error`：按量、价、利润率、FCF 和股数逐变量比较；报告误差来源。
- `alert_precision`：重大提醒中最后有材料验证的比例，需注明样本周期及分母。
- `research_error_repeat_rate`：已知同类错误再次出现的频率；每次误判登记并在下一轮回归测试中复测。

以上指标不能预设或伪造效果数值。只有在历史当时可见、可核验的数据达到足够覆盖后才能报告实测表现。
