# Fundamental Intelligence Agent V1.3 — 升级说明

## 改动目标

这次不是单纯增加财报报告篇幅，而是把谷歌测试暴露的十类错误转为可审计、可阻断相关结论的规则。保留V1.2的Module S、旧历史自适应比较，以及V1.1的异常、管理层承诺和产业链交叉验证。

## 新增核心模块

1. **Module B（§2.2）正反证据与合同质量**：每个核心命题强制找最强正/反证与零假设，RPO/订单与采购承诺按产品/年限/现金流核对，禁止简单相抵。
2. **Module G（§2.3）有机增长与逐KPI定义追踪**：处理收购、硬件销售、产品结构、重新定义的RPO等；分部利润与集团共享成本强制对账。
3. **Module C（§2.4）现金流—资本投入—每股股东价值**：净利润到OCF的间接法、营运资本、现金CapEx、项目回报、融资用途与经济稀释分开处理。
4. **Module V（§2.5）事件前预期与估值闭环**：财报前一致预期快照、标准化EPS、EV↔股权价值桥、异常投资收益剔除、反向隐含假设；价格变化不得被当作某一跌因的因果证明。
5. **Module Q（§2.6）独立质量审核**：把研究交付状态与Agent表现状态分开，缺历史样本外测试或独立重算不能宣称“测试通过”。
6. **研究优先级重排**：Stage -1 先固定投资问题与事件前时点；Stage B/C/E/G/I引入新规则；首页强制展示重大缺口。

## 谷歌研究十类问题如何修复

| 原问题 | V1.3对应模块/强制动作 |
|---|---|
| 资本风险只有负面没有合同需求对照 | B1/B2：支持、反证与合同—CapEx双向匹配 |
| 有机增长与硬件销售混杂 | G1/G2：逐KPI定义 + 报告增长/有机增长桥 |
| 标准PE与股权价值桥不完整 | V2 + C3：非经常性EPS、EV/股权口径、稀释 |
| 未重建财报前一致预期 | Stage -1 + V1：时间戳，缺失则限制股价归因 |
| 未检查Cloud共享AI研发成本 | G3：分部→集团未分配费用对账 |
| 现金流只看负数没有归因 | C1：净利润→OCF→现金CapEx→FCF |
| 错误推断增发的真实用途 | C1/C3：融资用途与稀释分离 |
| RPO统计定义变化未发现 | G1 + B2：即使集团无结构断点也逐KPI审计 |
| 同行验证缺乏经济传导 | X + B + C：业务映射→时滞→利润及现金 |
| Agent写完报告自己宣布通过 | Q1–Q4：独立审计状态及不可变测试日志 |
