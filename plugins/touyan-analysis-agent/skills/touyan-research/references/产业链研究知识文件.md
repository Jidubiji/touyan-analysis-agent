

版本：v1.0  
用途：用于构建“面向美股二级市场投资人的产业链研究模块”。  
适用对象：AI 半导体、云计算、SaaS、互联网平台、电动车、GLP-1、创新药、银行、能源、资源、REITs、核电、数据中心、电力设备等产业链研究。

---

## 0. 核心定位

产业链研究模式不是估值报告，也不是行业百科。

它的核心任务是判断：

1. 行业当前处于什么阶段；
2. 产业链如何拆分；
3. 哪个环节掌握稀缺资源；
4. 哪个环节拥有议价权；
5. 利润池正在向哪里转移；
6. 哪些公司受益，哪些公司受损；
7. 市场是否已经充分定价；
8. 最大预期差和最大风险是什么；
9. 哪些指标可以验证或证伪投资逻辑。

底层逻辑：

> 先界定研究边界；  
> 再判断行业周期；  
> 再拆解产业链；  
> 再判断利润池和议价权；  
> 最后判断受益路径、市场定价和证伪指标。

---

## 1. 产业链研究边界

产业链研究模式必须避免以下问题：

1. 不直接输出目标价；
2. 不默认做 DCF；
3. 不把分析师目标价当成结论；
4. 不只介绍行业历史；
5. 不机械罗列上下游公司；
6. 不把“行业好”直接等同于“股票可以买”；
7. 不把“公司是龙头”直接等同于“估值合理”；
8. 不忽略市场是否已经充分定价。

每份报告必须先界定研究对象和研究范围。

如果用户输入范围过宽，例如“AI 产业链”“新能源产业链”“医药产业链”，默认聚焦美股二级市场最相关、最具投资意义的核心环节，并在报告开头说明未覆盖范围。

---

## 2. 数据来源要求

产业链研究必须使用最新可获得数据。

优先来源：

1. 公司 Investor Relations；
2. SEC filings / 10-K / 10-Q / 8-K；
3. earnings release；
4. earnings call transcript；
5. 交易所、监管机构、行业协会、央行或政府统计；
6. 权威市场数据源；
7. 高质量财经媒体；
8. 分析师一致预期仅作参考，不得替代独立判断。

如果不同来源数据冲突，必须说明差异，并采用保守或最可核验口径。

所有关键数据必须注明来源或说明口径。

对最新市场、财报、订单、capex、监管、价格、供需数据，必须联网核验。

## 3. 产业链研究标准输出格式

每次产业链研究都默认输出完整报告。

除非用户明确要求“简单说”“简版”“只给结论”“100 字以内”，否则不得输出简版。

标准格式如下：

# [行业 / 公司 / 主题] 产业链研究

## 0. 一句话结论

用 2–3 句话直接回答：

- 当前产业链处于什么阶段；
- 哪个环节议价权最强；
- 投资机会主要来自哪里；
- 最大风险是什么。

---

## 1. 研究对象界定

必须包括：

- 研究对象；
- 产业链范围；
- 核心产品 / 服务；
- 主要需求来源；
- 主要供给来源；
- 本次研究重点；
- 本次研究不覆盖的内容。

---

## 2. 行业周期位置

输出表格：

| 维度 | 当前判断 | 变化方向 | 投资含义 |
|---|---|---|---|
| 需求 | 强 / 中 / 弱 | 改善 / 恶化 / 稳定 |  |
| 供给 | 紧张 / 平衡 / 过剩 | 改善 / 恶化 / 稳定 |  |
| 库存 | 去库 / 补库 / 高库存 / 低库存 |  |  |
| 价格 | 上行 / 下行 / 稳定 |  |  |
| 成本 | 上行 / 下行 / 稳定 |  |  |
| 资本开支 | 扩张 / 收缩 / 克制 |  |  |
| 竞争格局 | 改善 / 恶化 / 稳定 |  |  |

必须给出结论：

- 当前行业处于：上行 / 下行 / 分化 / 稳定；
- 更像是周期机会、结构性机会，还是主题预期驱动机会。

---

## 3. 产业链拆解

输出表格：

| 环节 | 主要内容 | 代表公司 | 议价权 | 利润池趋势 |
|---|---|---|---|---|
| 上游 | 原材料、设备、IP、能源、资金等 |  | 强 / 中 / 弱 | 扩张 / 收缩 / 稳定 |
| 中游 | 制造、封装、平台、基础设施等 |  | 强 / 中 / 弱 | 扩张 / 收缩 / 稳定 |
| 下游 | 品牌、客户、应用、渠道、终端需求 |  | 强 / 中 / 弱 | 扩张 / 收缩 / 稳定 |

必须指出：

1. 当前产业链瓶颈在哪里；
2. 谁掌握稀缺资源；
3. 谁承担最大资本开支；
4. 谁最容易被价格竞争挤压；
5. 谁最容易被技术替代。

---

## 4. 利润池与议价权分析

必须回答：

1. 行业收入增长是否能转化为利润增长；
2. 利润主要集中在哪个环节；
3. 哪个环节拥有定价权；
4. 哪个环节承担最大成本压力；
5. 哪个环节资本开支最大；
6. 哪个环节最容易被技术替代；
7. 哪个环节商业模式最好。

输出表格：

| 环节 | 收入弹性 | 利润率弹性 | 资本开支压力 | 技术替代风险 | 综合吸引力 |
|---|---:|---:|---:|---:|---:|
| 上游 | 高 / 中 / 低 | 高 / 中 / 低 | 高 / 中 / 低 | 高 / 中 / 低 | 高 / 中 / 低 |
| 中游 |  |  |  |  |  |
| 下游 |  |  |  |  |  |

结论必须明确：

> 当前利润池正在向 [某环节] 集中 / 转移 / 扩散。

---

## 5. 产业链环节吸引力评分

必须对主要环节进行 1–5 分评分。

输出表格：

| 环节 | 需求弹性 | 供给壁垒 | 议价权 | 利润率弹性 | 估值未定价程度 | 综合吸引力 |
|---|---:|---:|---:|---:|---:|---:|

评分含义：

1 = 很弱  
2 = 偏弱  
3 = 中性  
4 = 较强  
5 = 很强

综合吸引力最高的环节，不一定是收入规模最大的环节，而是风险收益比最好的环节。

---

## 6. 受益路径与公司映射

对每个公司必须说明受益路径。

输出表格：

| 公司 | 所处环节 | 受益路径 | 弹性来源 | 验证指标 | 风险 |
|---|---|---|---|---|---|

受益路径类型包括：

1. 量增；
2. 价涨；
3. 毛利率提升；
4. 份额提升；
5. 产品结构升级；
6. 资本开支拉动；
7. 估值重估；
8. 政策或监管变化。

公司分类：

| 类型 | 定义 |
|---|---|
| 核心受益 | 直接受益于需求增长、供给瓶颈、价格上涨或利润池扩张 |
| 次级受益 | 间接受益，但弹性或确定性较弱 |
| 潜在受损 | 受到成本上升、价格竞争、技术替代或需求转移冲击 |
| 观察名单 | 逻辑存在，但数据尚未验证 |

不得因为公司知名度高就默认列为核心受益。

---

## 7. 市场定价与预期差

必须判断：

1. 市场已经定价了什么；
2. 市场可能低估了什么；
3. 市场可能高估了什么；
4. 当前机会来自基本面改善，还是估值重估；
5. 风险来自基本面反转，还是预期过高。

输出表格：

| 项目 | 判断 |
|---|---|
| 已充分定价 |  |
| 可能低估 |  |
| 可能高估 |  |
| 最大预期差 |  |
| 最大风险 |  |

必须区分：

- 基本面趋势；
- 市场预期；
- 股价定价；
- 未来预期差。

不得因为产业链景气就直接得出“值得买”的结论。

---

## 8. 时间维度：短中长期机会

必须区分产业链机会的时间维度。

输出表格：

| 时间维度 | 主要驱动 | 受益环节 | 风险 |
|---|---|---|---|
| 0–6 个月 | 订单、价格、库存、财报催化 |  |  |
| 6–18 个月 | 产能释放、需求扩散、利润率变化 |  |  |
| 18 个月以上 | 技术替代、行业格局、长期渗透率 |  |  |

不得把长期 TAM 故事直接当作短期投资机会。

---

## 9. 核心跟踪指标与证伪指标

根据行业选择 5–10 个最重要指标，不得机械罗列。

输出表格：

| 指标 | 当前方向 | 观察意义 | 若恶化意味着什么 |
|---|---|---|---|

必须标记 1–3 个红线指标。

还必须给出 3–5 个证伪指标：

| 投资逻辑 | 证伪指标 | 触发后含义 |
|---|---|---|
| 需求持续高景气 | 订单增速放缓 / backlog 下降 / 客户 capex 下修 | 需求逻辑削弱 |
| 供给瓶颈支撑价格 | 交付周期缩短 / 库存上升 / 新产能集中释放 | 价格弹性下降 |
| 龙头议价权增强 | 毛利率下降 / ASP 下行 / 份额流失 | 议价权被削弱 |

---

## 10. 投资结论

最后固定输出：

| 结论项 | 判断 |
|---|---|
| 行业阶段 | 上行 / 下行 / 分化 / 稳定 |
| 最强环节 |  |
| 利润池方向 | 向上游 / 中游 / 下游 / 平台 / 设备 / 资源转移 |
| 核心受益者 |  |
| 次级受益者 |  |
| 最大预期差 |  |
| 最大风险 |  |
| 需要跟踪的红线指标 |  |
| 投资含义 | 积极关注 / 结构性机会 / 谨慎观察 / 风险偏高 |

最后必须用一句话总结：

> 当前产业链的投资机会主要来自 [需求增长 / 供给瓶颈 / 利润池转移 / 估值修复 / 市场预期差]，但需要警惕 [最大风险]。

# 5. 产业链研究执行守则

1. 产业链研究必须服务于投资判断，不写成百科介绍。
2. 必须先界定研究边界，避免范围过宽。
3. 必须判断行业周期位置。
4. 必须拆分上游、中游、下游和关键子环节。
5. 必须判断议价权和利润池变化。
6. 必须对产业链环节进行吸引力评分。
7. 必须区分核心受益、次级受益、潜在受损和观察名单。
8. 必须分析市场是否已经充分定价。
9. 必须给出核心跟踪指标、红线指标和证伪指标。
10. 必须区分短期、中期、长期机会。
11. 不默认输出目标价，不默认做 DCF。
12. 行业景气不等于股票值得买。
13. 必须区分好产业链、好公司、好股票、好交易。
14. 所有关键数据必须注明来源或说明口径。
15. 对最新市场、财报、订单、capex、监管、价格、供需数据，必须联网核验。
